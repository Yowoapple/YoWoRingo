# YoWoRingo

台湾・新北市出身、YoWoRingo（曾博文）のポートフォリオサイトです。地震情報コミュニティ「地牛記録小組（TWERG）」の創設者であり、ゲーム開発とストリートフォトにも取り組んでおります。

本サイトは、テンプレートに名前を差し替えただけのものではございません。各セクションをそれぞれひとつのインタラクションデザインとして捉え、フレームワークを用いず、JavaScript と CSS によってすべて手作業で制作いたしました。ピクセルで構成された証明写真、手に取って投げられる名前、ブラウザ上でリアルタイムに生成される音楽、そしてスクロールでズームしていく写真展をご用意しております。

<br>

## デザインコンセプト

### 色は、何かが起きたときだけ

サイト全体は、ほぼ黒に近い `#0B0B0C`、紙のような白 `#EFEEEA`、そして控えめなグレー `#85847F` の3色で構成しております。その静けさを破る唯一の色が、ウルトラマリン `#2B3BFF` です。

この色を装飾として用いることはございません。ホバー、画面遷移、再生中の楽曲、閲覧中のセクション、キーボードで選択された要素など、「何かが起きた瞬間」にのみ表示いたします。青が現れたときは、そこで何かが起きている合図です。

### 文字そのものがインターフェース

本サイトの文字は、単にフェードインするだけではございません。分解され、再構成され、ときには放り投げられます。名前は数式として表現し、スクロールに合わせて Day 001 から Day 100 までカウントが進みます。見出しは大胆な文字サイズで厳密なグリッドに配置し、周囲には十分な余白を設けております。

このアプローチは、[RAYRAYlab](https://rayraylab.com)、[Plus X](https://15th.plus-ex.com)、[DOES](https://does.kr) をはじめとする韓国のデザインスタジオから着想を得たものです。モノクロームを基調に、極限まで大きな文字、精緻なレイアウト、そして色彩への節度を大切にしております。

### 最もフォーマルな写真を、最も自由な場所に

サイトを開くと、まず少し硬い印象の証明写真が表示されます。これは意図的な演出です。サイトの他の部分はまったく異なる表情を持っており、その対比こそが見どころとなっております。カーソルを重ねると顔がピクセルに崩れ、スクロールすると写真全体が飛び散り、名前として再構成されます。

### 音は、許可をいただいてから

サイトに命を吹き込むのは、動きだけではございません。クリック、シャッター、衝突のひとつひとつに小さな効果音を用意し、BGM も制作いたしました。

ただし、入口で「Enter with sound」をお選びいただくまで、音が鳴ることは一切ございません。また、音声ファイルは一つも読み込んでおらず、すべての音を Web Audio API によってリアルタイムに合成しております。

### 誠実さも、デザインの一部

作品ページでは、何を作り、なぜそうしたのかのみを記載しております。地震のリプレイでは、手法が有効に機能した事例だけでなく、かえって結果が悪化した二つの事例もそのまま掲載いたしました。成功例だけを並べたポートフォリオでは、真の信頼は得られないと考えております。

## 見どころ

### Pixel to Person

Canvas 2D で描画した証明写真は、写真から色を抽出した無数の正方形で構成されております。各ピクセルはばね物理でカーソルに反応し、スクロールに合わせて新たな位置へ移動して名前を形作ります。画面幅が狭い場合や処理性能が控えめな端末では、ピクセルの粒度を自動的に調整し、滑らかな表示を保ちます。

### Physics Playground

名前の一文字一文字、ストーリーに登場するキーワード、そして四つの作品カードは、すべて実際の剛体として動作いたします（Matter.js）。つかんで投げる、Shake ボタンで箱ごと揺らすといった操作が可能で、作品カードをクリックするとその作品ページへ移動いたします。スマートフォンでは端末を傾けて重力の向きを変えることもできます（iOS では事前に許可を求めます）。演算はこのセクションが表示されている間のみ行います。

作品一覧は大きな文字で一行ずつ並べております。行にカーソルを合わせると、その行がウルトラマリンに染まり、プレビューカードがわずかな慣性をともなってカーソルに追従いたします。

### Dynamic Island と自動生成の音楽

画面上部のピルには、現在閲覧中のセクションが表示されます。クリックすると弾むように広がり、音楽プレイヤーへと変化いたします。この形状の変化は、CSS の `linear()` で記述したばね曲線によるものです。

BGM「Got any Ringo?」は、84 BPM・32 小節のループをブラウザがリアルタイムに演奏しております。別のページへ移動しても同じ位置から再生を続け、ページを離れる前には穏やかにフェードアウトいたします。

どの画面でも <kbd>Ctrl</kbd> + <kbd>K</kbd> を押していただくと、各セクションやページへの移動、メールアドレスのコピー、サウンドの切り替え、言語の切り替えを素早く行えます。スマートフォンでは全画面のシートとして表示いたします。なお、一覧には表示されないコマンドもございます。

### Focal Length（焦点距離）

54 枚のストリートフォトを、焦点距離 23 mm から 439 mm の順に掲載しております。このページでは、スクロールがズームリングの役割を果たします。右側のレンズスケールは対数目盛で、画角が狭まるにつれてファインダーの枠も絞られ、画面の隅には現在の焦点距離と画角がリアルタイムに表示されます。写真を開くと、ビューアーがその写真の主要な色に染まり、シャッター音が鳴ります。

### Beyond the Point：地震リプレイ

台湾で発生した三つの地震を、インタラクティブに振り返るリプレイです。境界線を左右にドラッグすると、従来の点震源による推定と、破壊の指向性を考慮した推定を比較していただけます。タイムラインを T+0 秒から T+60 秒まで動かすと、S 波の波面と主要都市のグラフが連動して変化いたします。データはすべて事前にオフラインで算出したもので、ページ上には結果のみを掲載し、アルゴリズムは含めておりません。

## 3 言語対応、レイアウトシフトはゼロ

本サイトは英語を基本としております。ブラウザの言語設定が中国語の場合は、繁体字または簡体字へ自動的に切り替わります。右上の地球儀ボタンから、EN、繁、简 を順に切り替えていただけます。

- **変換ではなく、ローカライズ。** 繁体字は台湾で使われる表現で執筆し、簡体字は字形の変換にとどまらず、「视频」「简历」「烈度」など中国大陸で一般的な用語に置き換えております。
- **切り替えても画面が動きません。** 繁体字と簡体字で同じ可変フォント・同じウェイト範囲を使用しているため、切り替えてもページ上の行が一行もずれません。お読みいただいていた段落は、切り替え後も同じ位置にとどまります。
- **クリックの前に準備を完了。** ブラウザが待機している間に次の言語の辞書を先読みし、ボタンにカーソルを合わせた時点でフォントの読み込みを開始いたします。そのため、クリックした瞬間にほぼ遅延なく切り替わります。
- **フォントは軽量に。** HarmonyOS Sans は実際に使用する文字だけに絞り込み、二つのファイルに分割しております。英語のページを閲覧する際に必要な中国語の文字データは、わずか 9 KB です。

## アクセシビリティ

インタラクションが豊かであっても、誰かを置き去りにすることがあってはならないと考えております。

- **キーボードだけで操作可能。** Playground の作品カード、Dynamic Island、音楽プレイヤー、写真ビューアーを含むすべての要素を、<kbd>Tab</kbd>、<kbd>Enter</kbd>、<kbd>Esc</kbd>、矢印キーで操作していただけます。
- **本文へのスキップ。** 各ページで最初に <kbd>Tab</kbd> を押すと、ナビゲーションを飛ばして本文へ移動するリンクが表示されます。
- **ダイアログで迷わない設計。** コマンドパレットや写真ビューアーを開いている間は背後のページを選択できないようにし、閉じた後はフォーカスを元の位置へお戻しいたします。
- **スクリーンリーダーへの配慮。** アイコンボタンにはラベルを付与し、装飾用のキャンバスは読み上げ対象から除外しております。すべてのセクションに見出しを、すべての写真に説明文を設け、通知は読み上げられ、ページの言語情報も言語の切り替えに合わせて更新されます。
- **「視差効果を減らす」設定を尊重。** OS で動きを抑える設定を有効にしている場合、スムーズスクロール、ピクセルのオープニング、スクロール時のフェードイン、画面遷移のアニメーションを控え、コンテンツをそのまま表示いたします。

## パフォーマンス

- キャンバスのアニメーションと物理演算は、セクションが画面外に出た時点で停止いたします。
- ピクセルの密度は端末の性能に応じて自動的に調整いたします。
- 写真は AVIF と WebP の2形式・3サイズでご用意し、ぼかしプレースホルダーと主要色を添えて、必要になった時点で読み込みます。
- デモ動画は、表示される直前まで読み込みを行いません。
- 中国語の辞書とフォントは、必要なときにのみ読み込みます。
- デスクトップでの実測値：最大コンテンツの描画は約 0.2 秒、累積レイアウトシフトは 0 です。

## ディレクトリ構成

```
index.html, photography/, works/{twerg,plum,galgame}/, 404.html   各ページ
src/css/        デザイントークン、基本スタイル、コンポーネント、ページ別スタイル
src/js/         エントリーポイント、サイト共通の外枠、機能モジュール、ページ別スクリプト
src/i18n/       繁体字・簡体字の辞書
src/data/       写真のメタデータと事前計算済みのリプレイデータ
public/         処理済みの画像、フォント、動画、アイコン、共有用画像
scripts/        素材処理スクリプト（写真、証明写真、フォント、多言語、ブランド）
docs/readme/    本 README で使用しているスクリーンショット
```

## ローカルでの実行方法

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # 本番用ビルドを dist/ に出力
npm run preview    # 本番用ビルドをプレビュー
```

素材処理コマンド（`npm run photos`、`portrait`、`works`、`fonts`、`i18n`、`brand`、`readme`）は、元データから `public/` 内の素材をすべて再生成するものです。ただし、元データ（原寸の写真やフォントの原本など）は本リポジトリに含めておりませんため、クローン直後の環境ではこれらのコマンドを実行できません。処理済みの成果物は、すでにリポジトリに含まれております。
